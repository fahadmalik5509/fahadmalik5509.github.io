LUDO · UI REVAMP

Design System Explorer

Nine candidate visual directions for the new Ludo UI. Every tile renders the identical component group — palette, type, buttons, avatars, HUD pills, dice, toggles, progress, badges, cards and icon orbs — so they compare like-for-like.

Method. The "grounded" set is built the way human design-system authors work: each direction derives from Ludo's own world — its origin as the Mughal game Pachisi, cowrie-shell dice, the four-armed cross, the race home — carries a distinctive type pairing, and commits to one signature move, with restraint everywhere else.
